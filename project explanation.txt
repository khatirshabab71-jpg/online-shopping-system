Welcome! This document was written specifically for beginners/students to help you

all the technologies (HTML, CSS, JavaScript, Python, MySQL) connect together.

-------------------------------------------------------------------------------
1. BIG PICTURE: HOW THE SYSTEM WORKS (THE ARCHITECTURE)
-------------------------------------------------------------------------------
Think of an online shopping website like a restaurant:

  1. FRONTEND (HTML + CSS + JavaScript) -> "The Dining Area & Menu"
     - What the user sees in the browser.
     - HTML provides the structure (the pages, text, buttons, forms).
     - CSS provides the styling (colors, fonts, layout, hover effects).
     - JavaScript handles interactive features (adding items to cart, button clicks, form validation).

  2. BACKEND (Python) -> "The Waiter & Kitchen Manager"
     - Runs on the server (behind the scenes).
     - Receives requests from JavaScript (e.g., "Check if user password is correct", "Save new order").
     - Processes the data securely (hashes passwords with SHA-256 algorithm).
     - Sends responses back to JavaScript in JSON format (a standard text format for data).

  3. DATABASE (MySQL) -> "The Storage Room / Pantry"
     - Stores data permanently in structured tables (users, products, cart items, orders).
     - Even if the computer turns off, data in MySQL remains saved.

-------------------------------------------------------------------------------
2. HOW ALL PARTS CONNECT TOGETHER (STEP-BY-STEP DATA FLOW)
-------------------------------------------------------------------------------

Example Scenario: A Customer Places an Order

  Step 1 (HTML):
  User opens `checkout.html` in their web browser and fills in their address.

  Step 2 (CSS):
  `style.css` and `responsive.css` make the checkout form look beautiful and fit on mobile/desktop screens.

  Step 3 (JavaScript):
  When the user clicks "Place Order Now", `checkout.js` catches the event, checks that no fields are empty, and uses `fetch('http://localhost:8000/api/checkout')` to send the order details to the Python backend server.

  Step 4 (Python Backend):
  `server.py` receives the request and sends it to `orders.py`. `orders.py` verifies stock levels, calculates the total price + shipping fee, and calls `database.py`.

  Step 5 (MySQL Database):
  `database.py` executes SQL queries to insert the order into the `orders` table and `order_items` table in MySQL database `online_shopping`. It also reduces product stock in the `products` table.

  Step 6 (Response to User):
  Python sends back `{ "success": true, "order_id": 10025 }`. JavaScript reads this and redirects the customer to `order-confirmation.html?id=10025`.

3. DETAILED EXPLANATION OF EVERY FILE IN THE PROJECT
-------------------------------------------------------------------------------

====================================
A. FRONTEND HTML FILES (The Skeleton)
====================================
Location: `frontend/`

1. `index.html` (Customer Home Page)
   - The main storefront homepage.
   - Contains header, search bar, navigation bar, hero banner, category cards, featured products grid, hot deals, and footer.

2. `products.html` (All Products & Search Page)
   - Displays the complete catalog of products.
   - Includes a sidebar filter for categories, price sorting, stock status, and search box (displays "No products found." if zero results).

3. `product-details.html` (Product Details View)
   - Displays details for a single product: large product image, name, price, discount badge, description, stock status, quantity picker (-/+), and Add to Cart button.

4. `cart.html` (Shopping Cart Page)
   - Shows all items added to cart in a clean table with images, prices, quantity controls, subtotals, shipping fees, total price, and checkout button.

5. `checkout.html` (Order Checkout Page)
   - Form capturing customer name, email, phone, street address, city, postal code, and payment method (Cash on Delivery vs Simulated Card Payment).

6. `order-confirmation.html` (Order Receipt Page)
   - Displays receipt after placing an order: Order ID, customer info, itemized table, total amount, shipping address, and status ("Pending").

7. `orders.html` (My Orders History Page)
   - Shows a table of customer's previous orders with date, total price, payment method, and status badge.

8. `profile.html` (Customer Account Profile)
   - Allows users to view and update their name, phone number, default shipping address, and log out.

9. `login.html` (Customer Login Page)
   - Simple, clean login form with email and password fields.

10. `register.html` (Customer Registration Page)
    - Registration form capturing full name, email, phone, password, confirm password, and address.

11. `admin/login.html` (Admin Authentication Page)
    - Dedicated portal for website administrators to log in.

12. `admin/dashboard.html` (Admin Dashboard)
    - Displays metrics cards: Total Products, Total Users, Total Orders, Total Sales Revenue, Pending Orders, Low Stock items, and CSS inventory charts.

13. `admin/products.html` (Admin Product Inventory CRUD)
    - Table of all store products with Add Product modal dialog popup, Edit button, and Delete button with confirmation prompt.

14. `admin/users.html` (Admin Customer Directory)
    - Table displaying registered users list, emails, phone numbers, addresses, and registration dates.

15. `admin/orders.html` (Admin Order Management)
    - Table displaying customer orders with inline status dropdown selectors allowing admin to change status (Pending, Confirmed, Processing, Shipped, Delivered, Cancelled).


====================================
B. FRONTEND CSS FILES (The Design)
====================================
Location: `frontend/css/`

1. `style.css` (Main Customer Stylesheet)
   - Contains color variables (`:root`), typography, header styles, buttons, forms, product cards, hover animations, cart tables, and footer.

2. `admin.css` (Admin Panel Stylesheet)
   - Styles the admin dashboard, dark sidebar, metric cards, admin tables, status badges, and popup modal forms.

3. `responsive.css` (Responsive Media Queries)
   - Makes the website adapt automatically to different screen sizes:
     * Desktop: 4 products per row
     * Laptop: 3 products per row
     * Tablet: 2 products per row
     * Mobile: 1 product per row


====================================
C. FRONTEND JAVASCRIPT FILES (The Logic)
====================================
Location: `frontend/js/`

1. `main.js` (Global Utilities & API Helper)
   - Contains `apiFetch()` helper function to communicate with Python backend.
   - Handles localStorage keys, currency formatting (`$699.99`), and header user state.

2. `auth.js` (Authentication Logic)
   - Validates registration and login forms (checks email syntax, password length ≥ 6, matching passwords).
   - Manages user profile updates.

3. `products.js` (Products & Search Logic)
   - Dynamically creates product cards.
   - Handles real-time search queries (e.g., searching "phone", "laptop", "watch").
   - Controls category filtering and price sorting.

4. `cart.js` (Shopping Cart Logic)
   - Adds items to cart, updates quantities, removes items, calculates subtotals + shipping, and updates the cart counter badge in the header.

5. `checkout.js` (Checkout & Order Receipt Logic)
   - Validates checkout form inputs, toggles simulated card details box, generates order records, and renders the confirmation receipt.

6. `admin.js` (Admin Panel Interactivity)
   - Admin authentication check, metric calculations, product add/edit/delete modal control, and live order status dropdown handler.


====================================
D. BACKEND PYTHON FILES (The Server)
====================================
Location: `backend/`

1. `server.py` (Pure Python HTTP Web & REST API Server)
   - Built using Python's built-in `http.server.HTTPServer` and `BaseHTTPRequestHandler`.
   - Serves static frontend files (HTML, CSS, JS, Images) and routes JSON API requests (`/api/...`).

2. `config.py` (Configuration File)
   - Holds port (8000), host ('0.0.0.0'), MySQL credentials, and security secret salt.

3. `database.py` (Database Connection Manager)
   - Connects Python to MySQL using `mysql-connector-python`.
   - Contains `execute_query()` function to safely execute SQL queries and prevent SQL injection.

4. `auth.py` (User Auth & Security Module)
   - Hashes passwords using SHA-256 algorithm (`hashlib.sha256`).
   - Manages customer registration, login verification, and profile updates.

5. `products.py` (Product Operations Module)
   - Fetches product list from database, handles search queries, category filters, and product detail lookups.

6. `cart.py` (Cart Operations Module)
   - Adds, updates, and deletes items in cart. Validates quantity inputs to block invalid numbers (e.g. `-5`, `0`, `999999999`).

7. `orders.py` (Order Placement Module)
   - Validates inventory stock, creates order invoice records, deducts product stock, and generates order history.

8. `admin.py` (Admin Backend Module)
   - Handles admin login, calculates dashboard metrics (Revenue, Pending Orders, Low Stock), handles Product CRUD, and updates order status.


====================================
E. DATABASE FILE (The Data Storage)
====================================
Location: `database/`

1. `online_shopping.sql` (MySQL Schema & Seed Script)
   - Creates `online_shopping` database.
   - Defines 7 structured tables:
     1. `users` (Customer profiles)
     2. `admins` (Administrator accounts)
     3. `categories` (Product categories)
     4. `products` (Inventory items with price, discount, stock, rating)
     5. `cart` (Active shopping cart items)
     6. `orders` (Order headers with total amount, status, date)
     7. `order_items` (Individual line items inside an order)
   - Seeds default admin (`admin` / `admin123`) and 18 realistic sample products.

-------------------------------------------------------------------------------
4. HOW TO RUN AND USE THE PROJECT
-------------------------------------------------------------------------------
1. Import MySQL Database:
   Open terminal and run: `mysql -u root -p < database/online_shopping.sql`

2. Start the Python Backend Server:
   Run: `python backend/server.py`

3. Open Website in Browser:
   - Customer Storefront: `http://localhost:8000/index.html`
   - Admin Panel: `http://localhost:8000/admin/login.html` (Username: `admin`, Password: `admin123`)
